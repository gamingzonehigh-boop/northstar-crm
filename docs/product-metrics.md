# Product Metrics

## North Star Metric
**Time-to-trustworthy-insight:** time from upload completion to a user receiving an answer they can confidently act on.

## Input metrics
- Upload success rate
- Automatic schema mapping rate
- Rows requiring manual review
- Data-quality pass rate

## AI quality metrics
- Factual accuracy
- Evidence coverage
- Hallucination rate
- Clarification rate
- Recommendation acceptance rate

## Experience metrics
- Time-to-first-answer
- Median latency
- Repeat analysis rate
- Weekly active users

## Cost metrics
- Cost per AI interaction
- Tokens per successful task
- Cost per retained user
